##Welcome to Onsala Space Observatory's Tech Talk

 * When:        **Mondays 10-11 am**
 * Where:       [Onsala Space Observatory](https://www.google.se/maps/place/Onsala+rymdobservatorium,+Chalmers/@57.3961849,11.9082682,14z), Seminar room
 * Contact:     [TechTalk  mailing List](mailto:oso-techtalk.see@chalmers.se)

The idea for this is to be an informal meeting where we can discuss
tools/software packages/programming languages/general computing issues
that we use and encounter on a daily basis. The overall goal of this
is to learn from each other and help everyone to spend less time on
technicalities that others have already mastered.

Notes from the various presentations will be collected here and will
be listed under the [talks](http://yggdrasil.oso.chalmers.se/category/talks.html)
tag. The presenters should provide [me](mailto:michael.olberg@chalmers.se) 
with their notes in markdown format, i.e. the same format that is e.g. used
on [GitHub](https://github.com) to document projects. The syntax is described on the
[GitHub Help Pages](https://help.github.com/articles/basic-writing-and-formatting-syntax/).

We have a [mailing list](mailto:oso-techtalk.see@chalmers.se) that you can use to bring up
computing issues and where we will make announcments regarding the seminar. If you'd like to be
added to the list please contact [Camilla Andersson](mailto:camilla.andersson@chalmers.se).

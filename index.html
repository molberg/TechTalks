Welcome to Onsala Space Observatory's Tech Talk

  • When: every other Wednesday 1.30-2.30 pm
  • Where: Onsala Space Observatory, Conference Room on 2nd floor of Admin Building
  • Contact: TechTalk mailing List

The idea for this is to be an informal meeting where we can discuss tools/software packages/programming languages/general computing issues that we use and encounter on a daily basis. The overall goal of this is to learn from each other and help everyone to spend less time on technicalities that others have already mastered.

Notes from the various presentations will be collected here and will be listed under the talks tag. The presenters should provide me with their notes in markdown format, i.e. the same format that is e.g. used on GitHub to document projects. The syntax is described on the GitHub Help Pages.

We have a mailing list that you can use to bring up computing issues and where we will make announcments regarding the seminar. If you'd like to be added to the list please contact Robin Garnham or Franz Kirsten.
